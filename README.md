# PetMóvel

O PetMóvel é um site responsivo de banho e tosa em domicílio para cães e gatos, com atendimento na cidade de São Paulo.

O projeto apresenta os serviços oferecidos, explica como funciona o atendimento e permite que o usuário preencha um formulário de agendamento com consulta automática de endereço pelo CEP.

## Funcionalidades

- Menu responsivo com botão hambúrguer para celulares e tablets
- Apresentação dos serviços oferecidos
- Destaque para atendimento na cidade de São Paulo
- Carrossel automático de depoimentos
- Navegação manual pelo carrossel com setas e indicadores
- Botões de agendamento com rolagem até o formulário
- Formulário de contato e agendamento
- Máscara automática para telefone
- Máscara automática para CEP
- Consulta de endereço pela API ViaCEP
- Preenchimento automático de rua, bairro, cidade e estado
- Mensagens de validação e confirmação do formulário
- Layout adaptado para computador, tablet e celular

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Também é possível executar o projeto utilizando a extensão Live Server no Visual Studio Code.

## Organização das branches

O projeto foi desenvolvido utilizando diferentes branches:

- `main`: versão final e publicada do projeto
- `develop`: branch utilizada para reunir as alterações durante o desenvolvimento
- `feature/...`: branches utilizadas para desenvolver funcionalidades específicas

## Observações

O PetMóvel é um projeto fictício desenvolvido exclusivamente para fins educacionais.

O formulário realiza validações e apresenta uma mensagem de confirmação, mas não envia os dados para um servidor ou banco de dados.

Os nomes, clientes e depoimentos apresentados no site são fictícios.
